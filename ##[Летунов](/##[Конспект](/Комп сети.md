Согласно варианту №8, в строке приглашения необходимо вывести символы "|||":

Использованные команды Git Bash:

mkdir -p  Создание каталога с родительскими директориями
cd  Смена текущего каталога
echo "текст" > файл  Создание файла с записью текста
echo "текст" >> файл  Добавление текста в конец файла
cp  Копирование файлов
rm  Удаление файлов
rmdir  Удаление пустых каталогов
cat  Вывод содержимого файла
ls  Список файлов каталога
sort  Сортировка строк
clear  Очистка экрана терминала
export PS1  Настройка строки приглашения
